# TMA-SANDBOX
TMA-SANDBOX - A freeware tma webapp 


A lightweight browser-based Target Motion Analysis trainer inspired by Dangerous Waters.

Features:
- Bearing Fan
- Interactive TMA Ruler
- TMA Stack
- Ownship Maneuvers
- CPA Calculation
- Scenario Generator
- Time Compression

If the local version doesn't work use the online version:

https://mattiabeninati-sys.github.io/TMA-SANDBOX/
